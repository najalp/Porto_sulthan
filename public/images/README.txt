TEMPATKAN FOTO PROFIL KLIEN DI SINI
====================================
1. Minta foto portrait Sulthan yang berizin untuk publikasi.
2. Simpan dengan nama PERSIS: sulthan-portrait.jpg
3. Hindari kompresi berlebihan. Saran ukuran 1200 x 1600 pixel (portrait 3:4).
4. Jika file belum tersedia, halaman menggunakan identitas tipografis "SMI." sebagai fallback.
5. Jangan gunakan foto orang lain atau foto AI sebagai pengganti identitas Sulthan.
